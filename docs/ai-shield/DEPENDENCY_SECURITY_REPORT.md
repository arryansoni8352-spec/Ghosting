## Frontend (Node) — npm audit

### Before this hardening session
3 vulnerabilities (2 critical, 1 moderate) — all in vitest `^3.2.3`:
- `tinypool <=2.1.1` — GHSA-5gmw-xhrv-c9v3 (Critical: prototype pollution → RCE in workers)
- `vitest >=0.0.95` — GHSA-5gmw-xhrv-c9v3 (Critical, transitive via tinypool)
- `@vitest/mocker <=4.1.11` — GHSA-82fw-gwwq-j7x9 (Moderate: path traversal via mock redirect)

**None were in the production bundle** — confirmed by `grep -rl "vitest\|tinypool" dist/`.

### Action taken
- Upgraded `vitest` `^3.2.3` → `^5.1.0` (installed: `5.1.0`)
- Upgraded `vite` `^6.3.5` → `^6.4.6` (required by vitest 5 peer deps)
- Updated `tests/setup.ts` import to `@testing-library/jest-dom/vitest` (vitest 5 type change)
- 130 website tests: still pass. TypeScript build: succeeds. Both CSP build variants: pass.

                    picomatch → micromatch → fast-glob, readdirp, sucrase
