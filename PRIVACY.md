# Privacy Policy

**VeilGuard** is a local-first image-protection research application. Your privacy is fundamental to its design.

## What VeilGuard Does NOT Do

- ❌ Upload your photos, thumbnails or file paths to any server
- ❌ Collect telemetry, usage analytics or crash reports without your explicit consent
- ❌ Require account creation or login
- ❌ Share data with third parties
- ❌ Access any image file you have not explicitly selected

## What VeilGuard Stores Locally

- **Application preferences** — stored in your OS's standard application data directory
- **Optional processing history** — a local log of files you have processed (can be disabled and cleared in Settings)
- **Temporary processing files** — written to a system temp directory and deleted after each session

## Network Access

VeilGuard performs **no network requests** during normal image processing.

Network access occurs only for:
- **Optional model downloads** — if a research algorithm requires downloading model weights, you are notified and must approve before the download begins
- **Dependency installation** — only during developer setup (npm install, pip install)

## Logs and Diagnostics

Application logs do not include image content, file paths or personal information. Logs are stored locally and can be cleared from Settings → Diagnostics.

## Children's Privacy

VeilGuard is not directed at children under 13 and does not knowingly collect information from children.

## Changes to This Policy

Any changes to this privacy policy will be documented in the changelog and will not reduce your privacy without explicit notification.

## Contact & Security

To report security vulnerabilities or privacy concerns, please open a private GitHub Security Advisory in the repository or contact the project maintainers via the public GitHub repository discussions.
